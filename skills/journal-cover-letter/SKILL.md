# Journal Cover Letter

根据稿件和目标刊，起草面向编辑的英文 cover letter：把适配和新意讲清楚，完成该刊强制披露，避免常见减分项。信只能提供语境，不能把弱稿变强，也不能保证送审。

本文件可单独交给本地 Agent 使用。更完整的出处与短引见 `references/sources-2026-11-18.md`。规定依据为 2026-11-18 核查的官方指南与具名编辑观点；若与投稿当日官页冲突，以官页为准并告知作者。

## 硬规则

1. 先确认目标刊当前 Author Guidelines / Guide for Authors 和投稿系统自定义问题，不要用一种出版商的口径覆盖所有期刊。
2. 信主要给编辑看。默认按“仅编辑可见”处理机密信息（相关稿、利益冲突、回避审稿人等）。Nature / Cell Press 明确不与审稿人共享；目标刊若明示会共享，再调整措辞，但仍不把不宜公开的信息写得像给全体审稿人看。
3. 不要复述摘要或引言，不要贴错刊名，不要写稿件支撑不住的 `first` / `paradigm-shifting` / `of great interest to the readers` 一类空话。
4. 不得编造审稿人、利益冲突、预印本、先前拒稿史或相关投稿。缺信息就向作者确认，用【待确认】标出，不要自行填入。
5. 默认英文不超过 1 页（约 300–450 词），除非该刊另有规定。
6. 按下面的出版商分支决定：哪些内容必须写进信，哪些只进投稿系统。

## 工作流

1. 识别目标刊，选择分支。
2. 向作者收集必要事实；稿件里已有的进展与数据可以引用，但披露类信息必须作者确认。
3. 打开该刊当前指南（见各分支 URL），核对是否有改版。
4. 输出三部分：可粘贴的英文信；系统字段 checklist；【待确认】清单。
5. 交作者过目后再定稿。所有【待确认】未确认前，不要写成已确定事实。

### 分支判定

| 目标刊 | 分支 |
|---|---|
| ACS Catalysis | `ACS_Catalysis` |
| J. Phys. Chem. A | `ACS_JPC_A` |
| 其他 ACS 期刊 | `ACS_Generic`（先读该刊指南，再套用 ACS 披露逻辑） |
| Nature、Nature Communications 及其他 Nature Portfolio | `Nature_Portfolio` |
| Science | `Science` |
| Combustion and Flame，或其他 Elsevier 燃烧刊 | `Elsevier_EM` |
| Proceedings of the Combustion Institute | `PROCI` |
| 其他 STEM 期刊 | `Generic_STEM`，先读该刊指南再写 |

### 向作者确认的信息

- 完整题名、文章类型、目标刊；若已知，编辑姓名及是否有 presubmission 沟通
- 一句话关键进展（必须能在稿内找到证据）
- 为何适合该刊，或指定栏目 / Part / Section
- 相关稿：在投、已接收、或需同时提交的紧密相关工作
- 预印本服务器与 DOI（若有）
- 先前被拒的期刊、稿号、是否需要逐条说明如何修改
- 建议审稿人：姓名、单位、邮箱、专长，以及与作者有无师生或近五年合作
- 需回避的审稿人及理由
- 受邀投稿的邀请信息（PROCI 等）
- 利益冲突（若有）

## 通用结构

按分支增删段落，不要把所有项目都塞进每一封信。

```text
Dear [Editor name or Editor]:

We wish to submit the manuscript entitled "[Title]" as a [article type] to [Journal].

[Fit, 2–3 sentences. Concrete match to aims and scope or the named section.
For ACS Catalysis: the catalytic insight, not the technique stack.
For Combustion and Flame: the implication for a combustion process.]

[Advance, one short paragraph. What is new relative to prior work, with
one or two quantitative anchors if the manuscript has them.
Do not paste the abstract.]

[Compliance or confidential sentences required by the branch:
related work, preprint, prior decline and manuscript number,
acknowledgement of invitation, prior discussion with an editor.]

[Suggested or opposed reviewers only if this branch requires them
in the letter. Otherwise put a reminder in the system checklist.]

Sincerely,
[Corresponding author], on behalf of all authors
[Affiliation, email, ORCID]
```

不知道编辑姓名时写 `Dear Editor:`，不要编造称谓或人名。

## 分支规则

### ACS_Catalysis

每次投稿必须附 cover letter。信中应包含：

- 为何适合 ACS Catalysis，以及 key scientific advance（第 1 段讲对催化学科理解推进了什么，不堆方法名词）
- 若有预印本，注明服务器与 DOI
- 若曾被本刊或其他刊拒稿：写明 manuscript number，并说明如何修订；通常需要逐条回复
- **至少 4 名**合格建议审稿人（姓名、单位、邮箱、专长）。近五年无师生或合作关系。给真实专长理由，不要只堆姓名
- 若稿中有定量结果，信里至少带 1–2 个量化锚点

利益冲突、数据可用性、作者批准等声明，仅在当前指南要求写入信时才写；否则放进系统 checklist，避免与表格重复且说不清。

指南：<https://researcher-resources.acs.org/publish/author_guidelines?coden=accacs>

### ACS_JPC_A

- 强制附 cover letter，建议使用单位信头
- 写明拟投的 Part / Section，并说明 new physical insights 与 significance
- 投稿系统字段可能与信有意重复，两边保持一致；Part / Section 最终由编辑确定

指南：<https://researcher-resources.acs.org/publish/author_guidelines?coden=jpcafh>

### ACS_Generic

ACS 多家期刊要求每次投稿附信。先读该刊 Author Guidelines，再决定审稿人名单、预印本和拒稿史是否必须出现在信里；不要默认复制 ACS Catalysis 的“信内至少 4 名审稿人”规则。

### Nature_Portfolio

- *Nature* 官方写明 cover letter 为 optional，但仍应用来写机密信息，以及为何适合本刊
- 不要复述摘要或引言；信通常不与审稿人共享
- 可写：相关在投或已接收工作、与编辑的先前沟通、建议的独立审稿人、经作者确认的有限排除名单
- *Nature Communications*：相关稿须一并提交；说明是否与编辑谈过

参考：

- <https://www.nature.com/nature/for-authors/initial-submission>
- <https://www.nature.com/ncomms/submit/editorial-process>
- <https://support.nature.com/en/support/solutions/articles/6000245674-cover-letter>

### Science

Related Documents 中，cover letter 为唯一必传文件。按当前作者须知覆盖这些要素（有则写，无则不要编造）：

- 文章的 main point
- 公平审稿所需信息
- 是否有 presubmission 讨论
- 曾分享过稿件的同事
- 未在他刊审阅或发表的声明
- 若涉及人类或动物研究，相应伦理说明
- 数据可用性

指南：<https://www.science.org/content/page/science-information-authors>

### Elsevier_EM（含 Combustion and Flame）

Elsevier 通例：

- 一页以内，写 aim、主要 findings、与 scope 的适配、novelty
- **不要**把 funding、author declarations、suggested reviewers 或 opposed reviewers 写进信；这些走投稿系统的 Review Preferences（若该刊开启）
- 输出里单独给系统填写提示

*Combustion and Flame* 的 Guide for Authors 在 2026-11-18 未能直接核到原文，不要把第三方站点的 “Required” 当成已核实结论。投稿前必须再打开当前指南。投 CNF 时，信中应显式写对 combustion process 的意义，避免只写纯催化剂制备或与燃烧无关的纯气相动力学。

通例：<https://service.elsevier.com/app/answers/detail/a_id/155/supporthub/publishing/~/what-should-be-included-in-a-cover-letter%3F/>

### PROCI

- *Proceedings of the Combustion Institute* 为 invitation only
- 受邀应在信中 acknowledge the invitation（Elsevier 通例）
- 作者指令页可能需要登录；投稿前核当前 Author Instructions
- 其余先按 `Elsevier_EM`：除非当年指令明确要求，审稿人建议不要默认写进信

学会页：<https://www.combustioninstitute.org/the_proceedings_of_the_combust.php>

### Generic_STEM

无专页时：用通用结构，篇幅一页以内；机密信息写入信中并标【待确认】；审稿人写在信里还是系统里，以该刊指南为准。不要承诺这封信能决定送审。

## 输出格式

按这个顺序交给作者：

1. **英文信全文**，可直接粘贴
2. **系统字段 checklist**：本分支应在系统填写、不要重复，或不要写入信的项目
3. **【待确认】清单**：审稿人、利益冲突、预印本、相关稿、拒稿史、邀请函等
4. **一句预期说明**：信有助于减少“scope 或新意没讲清”这类 desk 风险，但不能保证送审；决定仍主要看稿

## 自检

- 刊名、文章类型、题名正确
- 未粘贴摘要；所写新意能在稿内找到依据
- 该分支强制项已覆盖，或缺项已标【待确认】
- Elsevier / PROCI 路径未把 funding、declarations、审稿人写入信
- ACS Catalysis 路径信内有至少 4 名审稿人槽位，并提醒利益冲突规则
- 篇幅约一页，无套话

## 依据摘记

编辑决策主要看稿，信提供语境与合规，不能把弱稿送审。见 *Nature Geoscience* 社论（2021）与 Cell Press 编辑观点（Catarina Sacristán；Milka Kostic）。信的作用因刊而异：*Nature* 为 optional，*Science* 与 ACS 多家为实质必交。审稿人写在信里还是系统里，ACS Catalysis 与 Elsevier 的官方要求相反，必须分支处理。
