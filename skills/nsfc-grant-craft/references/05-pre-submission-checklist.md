# NSFC 申请书提交前全维度终审清单（Checklist）

提交前应先运行自动化体检脚本：
```bash
python scripts/audit_proposal.py path/to/draft.md --type youth|general|key
```
再结合本清单执行人工+语义逐项核查。**原则：宁严勿松、精确定位、给出直接修改方案。**

---

## 一、形式审查与红线合规（“一票否决”区）

- [ ] **官方模板完整**：使用申报当年系统下载的对应类别最新模板，**未修改、删除或自创任何一级/二级提纲标题**（含“报告正文”字样及括号内说明文字）。
- [ ] **正文篇幅合规**：符合 2026+“瘦身提质”要求（正文原则上 **≤ 30 页**，建议 20 页以内精炼呈现）。
- [ ] **限项与资格核实**：核对申请人及所有主要参与者是否满足高级职称（合计 ≤ 2 项）或非高级职称（“1+2”模式）及同层次人才项目限项要求。
- [ ] **单位与合作单位一致**：境内校外参与者自动对应合作单位（总数 ≤ 2 个；青C无合作单位），合作单位名称与法人公章一字不差；高职人员单位不一致情况已如实说明。
- [ ] **“无”项不留空**：正在承担项目、已完成基金项目、其他需要说明的情况等栏目，无相关事项时均已规范填写“无”，未留空白。
- [ ] **AI 使用与科研诚信合规**：无任何虚构文献、虚假数据或未经核实的生成内容；已按当年基金委规定如实声明并标识 AI 辅助工具使用情况。

---

## 二、基本信息表与摘要核查

- [ ] **题目（≤ 25 字）**：简明、具体、新颖，体现“研究对象 + 核心科学问题/机理 + 特色手段”，不含“技术开发/应用推广”等偏工程词汇，全文题名一字不差。
- [ ] **代码与关键词**：第一申请代码选至最末级；研究属性（自由探索/目标导向及四类科学问题属性）已准确勾选；填满 **5 个中英文关键词**，顺序与含义严格对应、优先系统标准词。
- [ ] **中文摘要（严格 ≤ 400 字含标点）**：包含背景痛点、核心问题/新思路、主要研究内容与方法、科学意义四要素；无截断、无文献引用、无复杂公式。
- [ ] **英文摘要（≤ 4000 字符）**：与中文摘要核心要素和结论数量完全匹配，为地道科技英语意译而非机翻，无拼写与时态混乱。

---

## 三、全书内在逻辑一致性矩阵（最核心）

- [ ] **摘要 ↔ 正文**：摘要提到的所有核心方法、研究内容与预期目标在正文中均有明确落地，不超纲、不遗漏。
- [ ] **立项依据 ↔ 科学问题**：拟解决的关键科学问题（青C 2 个，面上 2–3 个）是从立项依据文献剖析中水到渠成引出的，而非凭空出现。
- [ ] **研究目标 ↔ 研究内容 ↔ 研究方案**：三者一一对应；目标宏观有限，内容具体可控（青C 3 项、面上 3–4 项），方案具体到变量、参数、仪器/软件及对照验证判据。
- [ ] **创新点 ↔ 研究内容**：创新点（青C 1–2 条，面上 2–3 条）与特色分开陈述，每条创新点在研究内容与方案中均有明确验证途径。
- [ ] **年度计划 ↔ 资助期限 & 研究内容**：起止年份严格对应申报类别（青C 3 年，面上 4 年，无拷贝旧本子错年份问题），完整覆盖全部研究内容且节点可考核。
- [ ] **研究基础 ↔ 方案可行性**：前期基础与预研图精准支撑本项目核心环节，且拿捏好分寸，未造成“项目已基本完成”的误判。

---

## 四、经费预算、团队与成果三方联动（面上/重点等适用）

- [ ] **新版三科目准确**：直接费用采用“设备费 / 业务费 / 劳务费”三科目结构，预算表数值与预算说明书金额完全一致。
- [ ] **外拨经费说明**：明确写明合作研究外拨资金方案，无外拨须显式写明“无外拨经费”。
- [ ] **预算 ↔ 方案联动**：方案中列出的耗材、外委测试（电镜/XPS/同步辐射等）、超算机时、差旅会议在业务费中均有合理测算。
- [ ] **预算 ↔ 预期成果 & 人数联动**：劳务费计算的博士/硕士人数与“总人数统计表”及“预期人才培养人数”一致；版面费/专利费测算与预期论文/专利数合理匹配。

---

## 五、图表、公式与参考文献核查

- [ ] **图表编号连续且无漏引**：`图 1, 图 2...`、`表 1, 表 2...` 编号连续；正文中引用的每个图号/表号均真实存在，且所有图表均在正文中被引用。
- [ ] **图片质量与隐私**：高清矢量或 ≥300 DPI 图片，无 PDF 低清截图、无文字裁切溢出、无乱码；Draw.io 导出图已通过 `check_export_metadata.py` 确认未嵌入完整可编辑源。
- [ ] **参考文献双向对齐**：正文 `[n]` 引用编号连续；正文引用的每条文献均在文末列表中存在，文末列表无未被引用的孤立文献。
- [ ] **参考文献质量与格式**：数量合理（青C 30–50 篇，面上 50–80 篇）；国际权威文献为主、含少量中文文献与本人工作；含近 3–5 年及申报前一年/当年最新文献；**作者列全**、期刊/卷期/页码/年份格式全文高度统一；全部 DOI/信息经人工核实无 AI 编造。

---

## 六、个人简历与附件核查（SWJTU 高频退修点）

- [ ] **简历版本与时间轴**：上传当年最新系统生成的 PDF 简历；工作经历最新一条写至“至今”，且单位和职称与简历首行完全一致；不同职称分段衔接无断档。
- [ ] **代表作规范（≤ 5 篇）**：全部上传论文 **PDF 全文**；严格按发表原貌列全作者，未手动加星号篡改署名；已正确勾选本人署名角色、勾选“本人”加粗，并按 2026 新规**如实说明本人学术贡献**；附件备注简述与本项目某研究内容的直接关联。
- [ ] **特殊附件齐备**：在职研究生导师同意函、无高职无博士学位推荐函、伦理审查批件、境外合作者同意函等（如涉及）已盖章/签字上传。
- [ ] **导出 PDF 终检**：系统生成最终申报书 PDF 后，**从头到尾亲自翻阅每一页**，确认公式无乱码、图片不丢图、页码不异常、附件均可正常打开。

---

## 七、终审报告输出格式

输出检查结果时，请按以下四档汇总：
1. **检查总览**：通过 `X` 项 / 警告 `X` 项 / 未通过 `X` 项 / 需人工确认 `X` 项。
2. **❌ 未通过项（必须修改）**：逐条列出问题、精准位置（章节/段落/行号）及直接可执行的修改方案。
3. **⚠️ 警告项（强烈建议优化）**：逐条说明潜在扣分风险及改进建议。
4. **✅ 通过项 & ❓ 待用户核实项**（如系统内限项记录、PDF 导出后视觉渲染等需申请人线下确认项）。
