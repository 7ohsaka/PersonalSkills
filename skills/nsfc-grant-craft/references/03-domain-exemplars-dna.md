# 专属学科高分范本写作 DNA（多尺度反应机理 / 燃烧催化 / 原位诊断 / 表界面耦合）

本参考深度拆解了本地精选的三份高分中标申请书范本——**周忠岳（2022 面上，同步辐射光电离质谱+推进剂多相反应动力学）**、**顾明明（青年基金，m-FID 激光吸收光谱高温高压燃烧诊断）**、**陈磊（2018 西南交大面上，单点摩擦化学+分子动力学+宏观抛光能量复合模型）**——提炼出高度适配**气-固表界面反应机理、C1–C2 燃料转化（如 OCM/ODHE/ESR）、自由基通道、原位质谱/光谱诊断、第一性原理 DFT/MD 计算与多尺度微动力学建模（MKM）**的专属写作范式。

## 二、专属多尺度气-固反应动力学申报书写作模板（方法论闭环）

针对“**实验反应器/原位诊断 + 量子化学/DFT 计算 + 多尺度微动力学模拟（Cantera/Chemkin-Pro）**”类课题，避免写成“实验做一套、DFT 算几张势能面、模拟拟合几条曲线”的**三张皮**，务必采用以下**四阶闭环架构**：

### 1. 立项依据的三线交汇设计
- **主线 A（反应体系与宏观痛点）**：从能源/化工/碳中和或高值转化需求切入，直指当前体系核心矛盾（如：高选择性与高转化率难以兼得、表面过度氧化与气相自由基偶联竞争机制不明、传统催化剂失活/积碳机制存疑）。
- **主线 B（原位实验与中间体探测瓶颈）**：剖析常规离线检测（如 GC 仅测稳定终产物）难以捕获短寿命活泼自由基/表界面中间体（如 `\ce{CH3*}`、表面活性氧物种等），强调原位/在线高灵敏度探测（如 SVUV-PIMS、低压/射流搅拌/固定床反应器联用）的不可替代性。
- **主线 C（理论计算与多尺度动力学建模局限）**：指出单纯依赖静态 DFT 势能面忽略了实际温度、压力、表面覆盖度及气-固耦合传质效应；而纯经验宏观动力学缺乏基元反应物理依据，亟需构建**热力学自洽的“表面引发—气相偶联”多尺度微动力学模型**。
- **自然收口（项目构想）**：提出“**在线/原位实验探测关键自由基与中间体（锚定反应网络节点） + DFT/过渡态理论与热力学一致性修正（厘清基元路径与速率参数） + 气-固耦合微动力学建模与 SA/ROP/DRC 解析（定量揭示主控路径与调控规律）**”的研究范式。

### 2. 研究内容与关键科学问题黄金组合
- **青年基金（3 项内容 + 2 个关键科学问题）**：
  - **内容 1**：模型体系/特征工况下的在线实验探测与活泼中间体/自由基定量演化规律（明确反应器类型、温度/压力/当量比/空速窗口及检测物种）。
  - **内容 2**：表界面活性位点演变与关键基元反应路径的量子化学/DFT 解析（明确电子态/自旋态、吸附与断键过渡态、表面物种与脱附自由基关系）。
  - **内容 3**：热力学自洽的气-固耦合微动力学模型构建与关键路径调控机制（明确平均场近似 MFA、UBI-QEP/BEP 混合参数估计、热力学一致性校正、Cantera/Chemkin-Pro 模拟与 SA/ROP/DRC 敏感度解析）。
  - **关键科学问题示例范式**：
    1. `【表界面本质问题】特定反应气氛/工况下，催化剂表界面活性物种的动态演变及其引发关键自由基（如甲基自由基）脱附与竞争氧化的微观机制是什么？`
    2. `【跨尺度耦合问题】表面催化基元反应与气相自由基链式反应之间如何发生动态耦合与竞争，其主控速率决定步骤随温度/压力/组分变化的定量规律如何表征？`
- **面上项目（可拓展为 4 项内容 + 2–3 个关键科学问题）**：在以上 3 项基础上，增加“多变量解耦对照实验 / 复杂真实工况或非稳态演化拓展 / 基于模型反向指导催化剂或工艺调控验证”。

### 3. 研究方案技术细节写法清单（既具体又不臃肿）
- **实验部分**：写清反应器构型（JSR / PBR / 低压微反应器）、工况窗口（温度范围、压力范围、配比、停留时间）、在线分析手段（SVUV-PIMS 光子能量扫描/光电离效率谱 PIE 区分同分异构体、GC 定量标定、误差控制措施）。
- **理论计算部分**：写清软件与可靠参数（如 VASP、PAW-PBE 泛函、截断能、力收敛阈值、过渡态搜索方法 CI-NEB/Dimer 与虚频验证、特定活性氧物种的电子自旋态建模依据；注意：**只写实际采用的方法，不盲目堆砌未使用的校正项如未采用 DFT-D3 则不写**）。
- **多尺度动力学建模部分**：写清模型架构（气相详细机理 + 表面微动力学机理耦合）、参数获取策略（关键步采用 DFT 计算 + 其余反应采用 UBI-QEP/BEP 关系估算）、**热力学一致性约束方法**（焓/熵联合优化确保正逆反应平衡自洽）、数值求解与路径解析工具链（如 Cantera 一维流动模拟 + Chemkin-Pro 开展敏感度分析 SA、生成速率分析 ROP、速率控制度分析 DRC）。

## 四、术语与格式微规范（学科一致性自检）

- **自由基与化学式**：全文统一写法（如统一使用 `CH₃•` 或正文约定的自由基规范符号，切忌前文写 `CH3*` 后文写 `•CH3` 又写 `CH3 自由基` 混用）。
- **物理量与单位**：数字与单位间统一半角空格（如 `1200 K`、`0.1–20 MPa`、`450 eV`、`0.05 eV/Å`，`%` 与 `℃` 按中文排版全文统一）；量纲规范（如活化能 `kJ/mol`、表观速率等）。
- **英文缩略语**：首次出现必须写“中文全称（英文全称，缩写）”，如 `同步辐射真空紫外光电离质谱（Synchrotron Vacuum Ultraviolet Photoionization Mass Spectrometry, SVUV-PIMS）`，后文统一用缩写。
