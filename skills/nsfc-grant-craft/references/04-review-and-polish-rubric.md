# 模拟通讯评审、对标分析与学术语言润色标准

本模块用于对已有申请书草稿（全文或单章）执行**资深函评/会评专家模拟审阅**、**对标优秀范本差距诊断**与**逐段学术语言润色**。

---

## 一、模拟通讯评审框架（100 分制 + 双同行视角）

执行模拟评审时，必须先识别**项目类型**（青C / 面上[自由探索或目标导向] / 重点 / 联合基金）并调整严苛侧重点，然后严格按以下四大维度打分与点评，**每一条批评必须引用原文具体章节或语句**。

### 1. 评分维度与核心观测点

#### 维度一：立项依据与科学问题（40 分）
- **科学问题质量（15 分）**：是否清晰、聚焦、具有独特性？是否为真正的“科学问题”（规律/机制/本质）而非“技术/工程问题”？是否落入同质化跟风或“a+b 简单拼盘”陷阱？科学问题属性（A/B/C/D）选择与论证是否自洽？
- **逻辑链与文献综述（15 分）**：是否形成 `大背景 → 具体方向分类综述 → 痛点/争议/瓶颈剖析 → 关键科学问题 → 本项目独特切入点` 的无缝漏斗？是否避免“综而不述”和“过度铺垫”？文献是否涵盖近 3–5 年顶刊及当年最新工作、是否遗漏标志性文献？
- **研究内容与目标一致性（10 分）**：目标是否有限且可核验？研究内容（青C 3 项，面上 3–4 项）是否紧扣科学问题、彼此递进/互补而非“东一榔头西一棒”？是否与关键科学问题形成严密映射？

#### 维度二：研究方案与可行性（30 分）
- **方案具体性与针对性（12 分）**：研究方案是否与研究内容一一对应？对象、变量、参数范围、表征/计算方法及对照验证判据是否清晰到“小同行能判断可操作”？是否回答了“为什么这个方案能解决你提出的瓶颈”？
- **技术路线与方法合理性（8 分）**：技术路线图（或逻辑架构）是否一目了然？实验与理论/计算之间是否为真正耦合闭环，而非“两张皮”？是否识别了核心难点并给出备选方案（Plan B）？
- **可行性与年度安排（10 分）**：理论可行性、方法可行性、预研证据、条件平台、团队构成五维是否扎实？工作量是否匹配资助期限（3年/4年）？年度节点是否可考核？

#### 维度三：创新性与学术价值（20 分）
- **实质性创新（12 分）**：是否清楚区分“特色（不同）”与“创新（高明）”？是否具备新体系、新方法或新机理的实质突破而非简单工具移植？创新点数量是否克制（青C 1–2 条，面上 2–3 条）且可验证？
- **学术价值与学风表达（8 分）**：对基础理论和潜在应用的推进是否客观可信？是否避免“首次/填补空白/国际领先/系统研究”等自我拔高或空泛词？

#### 维度四：研究基础、摘要与整体印象（10 分）
- **研究基础与支撑链（5 分）**：前期成果与代表作是否紧扣本项目？是否展示了恰到好处的预研数据（既证明可行，又不至于让评审误判“已经做完无需资助”）？
- **20 分钟阅读体验（5 分）**：题目（≤25字）与摘要（≤400字）是否信息密度极高、独立可读？大同行能否顺畅跟上逻辑？排版、图表清晰度、术语统一性是否体现严谨学风？

### 2. 不同项目类型评审权重微调
- **青年科学基金（青C）**：重点考察**问题聚焦度（切口小而深）+ 学术思路新颖度 + 申请人独立科研训练与创新潜力**；不苛求新方向有海量前期积累，但忌题目太大太空。
- **面上项目（自由探索类）**：重**原创学术思想 + 前沿科学价值 + 系统积累自然延伸**（思想极突出时可适度包容基础）。
- **面上项目（目标导向类）**：重**面向重大需求抽提的共性基础科学问题 + 创新解决路径 + 扎实基础与可落地指标**。
- **联合基金 / 重点项目**：重**精准回应指南/行业痛点 + 多学科或产学研实质协同 + 团队实力**。

## 二、对标分析工作流（对比优秀中标本子）

当用户提供草稿（可选附带参考范本，或默认对标本 Skill 内置的周忠岳/顾明明/陈磊高分范式）时，从 5 个维度输出量化差距表与可直接套用的改写示范：
1. **结构与篇幅占比**：立项依据（35–45%）、研究内容与方案（35–45%）、研究基础（15–20%）、关键问题数量、创新点数量、配图数、文献数与近 5 年占比。
2. **立项依据漏斗密度**：背景是否超 2 段？综述是否分类评述？科学问题是否水到渠成？
3. **方案解耦与可操作性**：是否存在明确变量解耦路线？是否给出量化参数、方程/模型框架及验证闭环？
4. **特色创新写法**：是否做到“特色讲不同、创新讲高明”及三段式表述？
5. **预研与基础呈现**：预研图是否有效支撑方案且避免“过度完成感”？

## 三、逐段学术语言润色标准与禁词黑名单

### 1. 五维润色原则（保留原意、最小必要修改、逐处说明理由）
1. **表述精炼（去虚词、强动宾）**：把“对……进行了系统的研究和分析”改为“阐明/揭示/解析了……”；删除“其实”“众所周知”“在一定程度上可以说是”等水词；避免每句都用“本项目拟……”开头。
2. **逻辑显性化**：补齐段首主题句与段间逻辑枢纽词（`然而`、`尽管如此`、`基于此`、`针对上述瓶颈`、`进而`）。
3. **语气拿捏**：**客观严谨、自信但不自大**；全文人称统一（统一用“本项目”“申请人”，忌混用“我们”“笔者”）；时态统一（现状用已然/现在时，拟开展工作用拟/将）。
4. **禁止口语与模糊表达**：
   - ❌ “做一下”“搞清楚”“看看效果”“开展一系列实验”“进行相关研究”“研究……的影响”
   - ✅ 替换为具体动宾短语 + 具体变量：`揭示……机理`、`阐明……机制`、`定量解析……演化规律`、`构建……耦合模型`、`突破……测量瓶颈`、`探明……调控机制`。
5. **格式标点洁癖**：中文正文用全角标点，英文摘要用半角标点；数字与单位间距统一；禁用感叹号和反问修辞（科学问题提问除外）。

### 2. NSFC 高风险禁词 / 慎用词黑名单

| 类别 | 禁用 / 高风险词汇 | 风险原因 | 推荐客观替代表述 |
| :--- | :--- | :--- | :--- |
| **绝对化自吹** | `首次`、`世界首创`、`国际领先`、`国际一流`、`填补国内外空白`、`彻底解决`、`必将取得重大突破` | 极易引发小同行反感甚至直接举反例证伪；“没人做 ≠ 值得做” | `尚缺乏系统认识`、`鲜见针对……的定量研究`、`区别于已有……方法，本项目提出……`、`有望为……提供新思路` |
| **空泛大词（SWJTU 重点提醒）** | `系统研究`、`全面总结`、`集成研究`、`深入探索一系列问题`、`开展相关研究` | 显得没有核心抓手与创新锋芒 | 直接写出具体的科学对象、关键变量、核心方法与目标产物 |
| **工程化偏离** | `技术开发`、`工程应用推广`、`设备研发与产业化`、`工艺优化（无底层机理）` | 偏离基金委“基础研究/应用基础研究”定位 | `……关键科学问题`、`……微观作用机制`、`为……工艺优化提供理论依据` |
| **过度谦虚/随意** | `尝试性地探索`、`初步看看`、`大致分析`、`搞清楚`、`也许/大概` | 显得信心不足、方案未想透、学风不够严谨 | `拟采用……方法定量解析……`、`通过……验证……假设` |

### 3. 逐段润色输出格式
每处修改必须呈现：
> **【位置】** 章节/段落号  
> **原文**：...  
> **修改**：...  
> **修改说明**：（标注归类：表述精炼 / 逻辑过渡 / 学术规范 / 去除高风险词 / 格式统一）
